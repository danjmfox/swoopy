# Swoopy — Product Vision

Bootstrapped from docs/PRD.md during DISCUSS wave for share-url-compression.

## Vision

A browser-based causal loop diagram tool for facilitators and coaches running systems thinking
sessions. Builds on Nicky Case's Loopy interaction model with a modern, maintainable stack. The
primary value is the **conversation while building** — the simulation is a shared reference, not a
predictive model.

## Primary User

Facilitator / coach / educator in an organisational change or agile adoption context. Not
necessarily technical. Needs to sketch quickly, run to test intuitions, and share for
asynchronous comment.
